# 台股功能（4）

2026-10-02。依使用者確認的桌機／手機圖稿實作；使用者另確認相似度指 ETF 持股重疊，並授權直接正式部署。

## 功能

- 依使用者更正，「篩選器」移至台股雷達上列，於雷達頁內切換；存股計算、畫板、泡泡圖、板塊輪動維持在市場指標工具列。
- 篩選器：62個條件欄位／開關、27組分派別量化參考模板、8個快速條件、範圍篩選、本機儲存組合、重設、結果排序／搜尋／逐批顯示、欄位明細、點股票返回原雷達。
- 桌機左側條件捲動；手機條件底部面板與固定執行列。沿用既有OX外框、導航與工具列動畫。
- 存股計算內分為「存股試算／ETF重疊比較」。試算採月底投入、價差成長與股息分開、可切股息再投入，展示資產曲線與逐年明細。
- ETF比較使用發行商完整股票清單；共同股票權重取最小值後加總，另列股票部位正規化相似度與配置後權重。列出各自日期、來源與股票部位覆蓋率，日期不同有提示。提供其他ETF清單CSV貼入比較。

## 資料與限制

- 盤後股票快照整合原台股雷達日K、TWSE／TPEx估值、月營收、一般業財報、股數與法人資料。不同資料期別逐股保留。
- 最新一般業綜合損益表為年初累計，毛利／營益／淨利率照此計算，未將累計EPS誤當單季。缺少歷史的單季EPS年增、PEG、近12月營收P/S、連續配息／EPS／營收、5年品質、完整52週與年線等不造值。
- LUVAI及第三方Rating／子分數未取得授權來源。介面可設定，但會說明未有資料；任何缺少必要欄位的股票一律排除。模板也標明待資料條件，絕不靜默省略。
- 初始ETF官方清單為元大0050、0051、0053、0055、0056、00713、00850；其餘可貼入清單。比較只涵蓋直接股票，不穿透ETF、不含現金與期貨。
- 收集腳本／排程獨立於原有台股資料流程，保留上次已驗證的基本資料並標記來源失敗。ETF Nuxt序列化使用字面值解析，不執行網站JavaScript。
