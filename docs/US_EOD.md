# OX 美股盤後模式

2026-10-01 使用者決定停止盤中資訊，將美股全站改為盤後選股／交易準備；Twelve Data 從方案移除。本文件優先於舊版盤中／widget 接入紀錄。

## 實際行為

- 首頁、雷達、泡泡圖、漲跌排行、相對 SPY 強弱與型態畫板讀取同一份已收盤快照。所有價格、成交量、量比與型態依已完成 K 線計算。
- 圖表提供日／週／月線。分鐘、小時、延長時段、盤中倒數與 TradingView 自動行情圖表不再使用；舊級別偏好遷移至日線。
- 不啟動圖表／報價／掃描快照的背景輪詢。進入美股時載入一次；使用者可按盤後狀態列的更新鍵讀取共享快照。
- 標示紐約交易日、實際收盤時間、資料來源、取得時間。收盤報價由日 K 的 close 推導，不是盤中 quote 改名。
- 周／月 K 僅納入完整交易期，缺少交易日則捨棄，不補造行情。分析至少需要 60 根完整同級別 K；月線不足時不產生候選。
- 使用既有紐約日曆（2025–2028）、夏令時間、假日與提早收盤規則。正常盤收盤後留一小時資料定稿緩衝；超出已知日曆停止收集。
- 訂單流、逐筆、委託深度等盤中功能不接入。其他市場與帳號模組不在本次改造範圍。

## 共用收集與發布

`node scripts/collect-us-eod.mjs` 每個標的一次日線請求，同時計算日／週／月 K、收盤報價與掃描结果，原子替換 `data/us-eod.json`。首頁、報價與掃描讀取此檔。公開快照只保存收盤摘要與分析，不把整個原始歷史池放入公開 Git。單檔圖表按需讀取日線，伺服器以股票／收盤交易日合併請求並快取；週／月共用同一份日線，不抓分鐘或即時 quote。此快取限同一暖啟動實例，冷啟動仍可能再請求，並非全域只抓一次的保證。

排程為週一至週五 UTC 23:00，亦即台灣次日 07:00；收集仍以紐約已完成交易日判定，不將周末或假日當新行情。排程是啟動收集時間，不是保證完成時間。每分鐘最高 8 次、總量採明確預算，429 即停止；SPY 缺失或有效來源不足九成時保留前次檔案。舊 Twelve Data 收集器與 API 路由停用。

**公開展示仍需資料使用權。** 僅在 `US_DATA_PROVIDER=finance-query` 且實際授權確認後設 `US_EXTERNAL_DISPLAY_CONFIRMED=true`，才允許公開資料收集／返回。改為盤後不代表原始資料免授權。未確認時回傳明確空狀態；私人資料不進 Git、不公開、不作假資料填充。

私人驗證：

```
node scripts/collect-us-eod.mjs --private-validation --input /path/to/verified-daily-json --output /tmp/ox-us-eod/bundle.json
US_PRIVATE_INPUT=/tmp/ox-us-eod/bundle.json npm run dev -- --us-private --port 4186
```

私人輸出強制放專案外；伺服器只綁定 127.0.0.1，仍檢查 socket、Host、Origin。公開 API 不接受私人模式旗標。
