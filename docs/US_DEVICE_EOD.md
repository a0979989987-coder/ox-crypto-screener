# OX 美股本機盤後功能

2026-10-01：使用者明確要求 OX 原生 K 線、雷達、泡泡、型態畫板與首頁資訊。免費 TradingView widget 不能提供這些功能所需的 OHLCV。公開資料供應尚未取得確認；這次以使用者選擇的個人盤後檔在瀏覽器內運作，不改公開資料授權旗標，不上傳檔案，不把私人歷史放進 Git。

## 使用

美股狀態列按「盤後檔」，選擇個人的 OX 盤後 JSON。有效 OHLCV、公司名稱與 SPY 基準在本機驗證，價格與分析重新計算；輸入內預先計算的行情／掃描結果不使用。匯入成功才原子替換 IndexedDB 資料，失敗保留前份可用資料。

首頁、雷達、泡泡、熱力圖、相對強弱、排行榜、型態畫板與原生圖表讀取同一份本機收盤資料。圖表沿用 OX 原生渲染及既有畫線元件／儲存，日／週／月線只包含完整交易期。型態縮圖使用真實 K 線；型態分析至少需要 60 根完整同級別 K。手機畫板支持畫路徑後掃描，泡泡可拖曳／縮放與點選股票。

檔案以瀏覽器和 origin 為範圍保存，GitHub Pages 與 Vercel 的本機資料彼此獨立；換裝置或清除網站資料需重新匯入。沒有背景輪詢，沒有每日自動更新；更新個人盤後檔需再匯入。尚未匯入的訪客維持官方免費圖表與參考名錄，OX 掃描不填造假資料。此模式不是公開全市場即時服務。

## 個人檔輸出

```sh
node scripts/export-us-device-eod.mjs --input /private/bundle.json --output /private/OX_US_EOD.json
```

此工具只接受已存在的私人收盤 bundle，輸出強制置於公開專案外。不請求新的 Twelve Data、盤中行情或免費 widget 原始資料。

## 名錄載入

2.6 MB 參考名錄改為以模組 URL 定位，兼容 GitHub Pages 子目錄。靜態來源失敗時改讀已允許該 origin 的公開名錄 API；成功名錄保存在本機，7 天內可直接重用，供應暫停時保留先前名錄。取消市場切換不啟動備援請求。失敗清單提供重試，無須重整整站。
