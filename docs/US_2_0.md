## API 診斷與決策

保留 Twelve Data。實際 production 請求確認 key 已由後端配置、AAPL 報價與歷史成功、TSM 可查 ADR；舊 radar／breadth／sectors 尚為 501。主要問題是目錄、行情與歷史未串成完整 UI／掃描管線，不能歸因為資料商只有幾檔股票。

直接取得官方 `/stocks?country=United%20States` 和 `/etf?country=United%20States` reference 目錄，過濾 USD、NYSE／NASDAQ／CBOE 的 common stock、ADR 和 ETF，排除 OTC、權證／優先股等不適合標的並去重。2026-09-30 目錄：**17,240**（普通股5,744、ADR393、ETF11,103）。這是供應商目錄分類，沒有宣稱所有代號都通過行情／歷史驗證。

私下低速實測20檔：20個有效報價、20檔400根日 K／合格分析。未授權的驗證 snapshot 沒有提交到公開 Git；正式環境不放 fixture。300～500 掃描目標已能設定（預設350、上限500），但**尚未取得300～500檔全池實測結果**。1H／4H 共用掃描已實作為可選收集級別，未啟用大池盤中收集；目前實測快照只有日線。

官方 2026-08-18 US equities 說明：預設盤中 feed 約為全市場成交量5%，不能標為 consolidated／全市場。公開展示 real-time 資料需確認 redistribution rights。EOD／歷史日級資料有不同授權規則；仍須核對實際帳號用途與 feed。API 成功不證明帳號已取得網站展示權。

正式新增 `quote-v2`、`chart-v2` 在 `US_EXTERNAL_DISPLAY_CONFIRMED !== true` 時回403。公開 preview 不回退旧資料端點繞過授權；localhost 可用舊後端進行既有接法私下驗證。金鑰只在後端／Actions secrets，不回傳或寫入資料檔。

## 更新、額度與部署

目錄／掃描由 `.github/workflows/update-us.yml` 共用收集，訪客讀相同快照。動態探索目錄、保留前次流動標的、依20個完整日的平均成交額與至少60根收線資料過濾；排除複雜ETF，股票／ADR與一般ETF可分開看。報價數與分析數只統計本輪成功者，空結果不覆蓋有效快照。

前端快照300秒、selected chart 正常盤60秒／休市300秒；後端 quote／recent bars 60秒、歷史24h、最多2個同時 upstream、有限 warm cache、429退避、請求合併。CDN與warm cache會減少相同請求，**不是跨Vercel實例的全域額度鎖**。

保守估算（正常盤，每訪客1張圖、每分鐘1次bars + 1次quote，未計CDN命中；開頁另至少1次歷史請求）：

| 同時訪客 | 最坏正常盤 credits/min | 同標的同參數理想共用後 |
|---:|---:|---:|
| 1 | 2 | 2 |
| 10 | 20 | 約2，跨實例／時間差仍可能更多 |
| 100 | 200 | 約2，不能視為額度保證 |

350檔日掃描約700 credits/run（350 quotes + 350 OHLCV），在8/min下約88分鐘；同時收1H和4H合計約1,400，8/min下超過目前110分鐘 job。批次 quote 按**每symbol**計費，不以每HTTP請求當一credit。Basic官方8/min、800/day只是比較基準，未確認現有帳號是Basic；350掃描加訪客在這個方案沒有足夠安全餘裕。需實際 quota 才可設定掃描量／級別及公開訪客容量。

未把持續WebSocket collector塞進短函式；目前無新增常駐基礎設施。Vercel 既有動態API仍同一個function，函式數不增加。GitHub Actions 沿原有快照寫回流程；未確認其剩餘分鐘額度，也未自動啟用。高併發需要後續核准的分散式額度／共用行情收集方案，100使用者未壓測。

上線前最少設定（不把key貼到聊天／前端）：

1. 核對現有 Twelve Data 網站展示授權，後端設定 `US_EXTERNAL_DISPLAY_CONFIRMED=true`、實際 `US_FEED_NAME`、`US_DATA_DELAY_SECONDS`、`US_VOLUME_SCOPE`、`US_EXTENDED_HOURS`。
2. 核對 credits/min／day 與 Actions 分鐘，設定 `US_API_CREDITS_PER_MINUTE`、`US_COLLECT_CREDIT_BUDGET`、`US_SCAN_TARGET`；可選 `US_SCAN_INTERVALS=1D,1H,4H`。共用 job 需要現有key作為Actions secret，或只透過現有 backend 收集。沒有新key的需求，但不要公開讀出後端secret。
3. 完成授權後跑共用收集與新端點／盤中驗收，再按原專案 Vercel／Pages 發布流程合併。這個版本不把 unlicensed private snapshot 發布到公開Git。
